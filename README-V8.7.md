# VoltFlow V8.7 — Project Command Center

This release unifies project operations into one focused workspace.

## Included
- No emoji icons in navigation tabs
- Architectural sidebar navigation
- Searchable project rail and status filters
- Project health score
- Progress and milestone path
- Tasks and priority tracking
- Unified activity timeline
- Project media overview
- Financial summary from estimates and invoices
- Schedule overview
- Operations Intelligence recommendations
- Mobile-responsive command center

## Installation
1. Replace the local repository contents with this package.
2. Run `docs/sql/V8-7-PROJECT-COMMAND-CENTER.sql` in Supabase SQL Editor.
3. Commit and push through GitHub Desktop.
4. After Vercel deploys, sign in to `admin.html` and open Project Command Center.

## Notes
This release preserves the existing CRM, estimating, billing, security, portals, field operations, website manager, and public pages.
