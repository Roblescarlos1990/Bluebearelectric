# VoltFlow V8.8 — Operations Intelligence

V8.8 turns the admin landing area into a prioritized operating dashboard.

## Included

- Executive KPI layer
- Universal cross-module search
- Rule-based proactive operational insights
- Project health scoring
- Consolidated activity stream
- Opportunity and schedule visibility
- Keyboard shortcut: Ctrl/Cmd + K focuses universal search
- Responsive desktop/tablet/mobile layout
- No emoji navigation
- Additive database foundation for notifications, saved searches, and insight feedback

## Install

1. Replace the repository contents with this package.
2. Commit and push through GitHub Desktop.
3. Run `docs/sql/V8-8-OPERATIONS-INTELLIGENCE.sql` in Supabase SQL Editor.
4. Redeploy through Vercel.
5. Open `/admin.html` and sign in.

## Notes

The operational insights are deterministic rules based on live data. They do not require an external AI API. This avoids fabricated recommendations and provides a dependable base for future AI-assisted operations.
