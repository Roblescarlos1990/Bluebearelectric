BLUE BEAR ELECTRIC V5.2 - PROJECT WORKSPACE

WHAT THIS ADDS
- Project Workspace tab inside admin.html
- Automatic project photo galleries by project and stage
- Before / During / After / Thermal / Drone / Reports / Warranty categories
- Estimate item builder
- Simple invoice creation from estimate subtotal
- Schedule event tracker
- Mobile-friendly admin tabs

BEFORE TESTING
1. Upload all extracted files to GitHub.
2. Let Vercel redeploy.
3. In Supabase SQL Editor, run V5-2-POLICIES.sql.
4. Open /admin.html.
5. Sign out and sign back in.

TEST FLOW
1. Add/open a project.
2. Go to Project Workspace.
3. Upload a project photo.
4. Add estimate line items.
5. Create an invoice.
6. Add a schedule event.

NOTES
- The invoice generator is a simple starter. It creates invoice records in Supabase.
- PDF exports, email sending, maps, employee portal, customer portal and AI proposal writer are next modules.
