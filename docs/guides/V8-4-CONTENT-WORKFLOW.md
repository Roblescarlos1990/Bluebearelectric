# V8.4 Content Workflow

## Media Library

Upload public website images to the `site-media` Supabase bucket from VoltFlow Admin → Website → Media Library.

Recommended categories:

- Hero
- Industrial
- Commercial
- Residential
- Solar & BESS
- Service & Repair
- Projects
- Trucks
- Logo
- Team
- Territory

## Content

The homepage headline, description, phone number, license, service-area wording and mission can be saved as Draft or Published.

## Services

Services can be added, reordered, hidden, or published without manually changing the public services cards.

## Portfolio

Portfolio records support Draft, Published and Archived states. Only Published records are visible to public users.

## Static fallback

Public HTML remains in the repository. If Supabase is unavailable, the website displays the current static content instead of appearing empty.
