VOLTFLOW V6

What is new:
- Dashboard 2.0 KPI cards
- CRM customer cards
- Project cards with Open Workspace button
- Project timeline / milestones
- Automatic project photo galleries
- Estimate builder with print estimate
- Invoice generator
- Schedule events
- AI-style proposal draft generator
- Mobile-friendly admin improvements

Install:
1. Upload/replace the full extracted folder in GitHub.
2. Let Vercel redeploy.
3. In Supabase SQL Editor, run V6-SQL.sql.
4. Open /admin.html and hard refresh.
5. Test: open project -> add milestone -> add estimate item -> create invoice -> add schedule -> generate proposal.

Note:
The proposal tool is a local template generator for now. A real AI API can be connected later through a secure server-side route.
