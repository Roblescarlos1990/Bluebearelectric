Blue Bear Electric V6.3 Command Center

What changed:
- New VoltFlow module sidebar
- Reports tab with live counts and simple charts
- AI Assistant tab for proposal draft generation
- Portal launcher tab
- Keeps V6.1/V6.2 project workspace, CRM, estimates, invoices, schedule, customer portal, and employee portal

Install:
1. Upload/replace the full extracted folder in GitHub.
2. Let Vercel redeploy.
3. Run V6-3-SQL.sql in Supabase SQL Editor. Optional but recommended for future modules.
4. Open /admin.html and hard refresh.
5. Confirm the header says VoltFlow V6.3.

Test:
- Dashboard loads stats
- Projects open in Workspace
- Reports tab shows cards/charts
- AI Assistant generates proposal draft after a project is open
- Customer and Employee portal buttons open their pages
