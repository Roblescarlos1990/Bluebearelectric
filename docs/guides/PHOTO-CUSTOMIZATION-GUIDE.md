# Photo Customization Guide

## Public website photos

Location: `assets/images/site/`

Current filenames used by the site:

- `logo.jpg` — navigation/footer logo
- `truck.jpg` — truck and interior page hero
- `switchgear.jpg` — homepage hero and about image
- `vfd.jpg` — industrial card
- `fuse-panel.jpg` — commercial card
- `instagram.jpg` — residential card
- `solar-field.jpg` — solar card
- `megger.jpg` — service/testing card
- `testing.jpg`, `mv-cabinet.jpg`, `burnt-combiner.jpg`, `solar-wire.jpg` — project gallery

The easiest replacement method is to upload a new image using the exact same filename. That avoids editing HTML.

## Recommended image sizes

- Hero/background: 1920×1080 or larger
- Service cards: 1200×800
- Project cards: 1200×900
- Logo: transparent PNG preferred, at least 800 px wide

## File naming

Use lowercase letters, numbers, and hyphens. Avoid spaces.
Example: `industrial-switchgear-01.jpg`
