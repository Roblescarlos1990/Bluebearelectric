## Individual photo control

Every public website image now has a permanent `data-photo-slot` identifier.

Admin path:

`Branding & Website → Individual Photo Location Manager`

You can:

- Filter by page
- Search exact image locations
- Preview the current image
- Upload a replacement for one exact location
- Edit alt text
- Publish or hide the replacement
- Restore the original repository image

Registered photo locations in this release: 39
