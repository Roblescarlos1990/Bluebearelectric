# VoltFlow V8 — SaaS Foundation

VoltFlow is the contractor operating platform. Blue Bear Electric remains the first tenant/company using the platform.

## V8 changes
- Renamed the internal operating system from **Blue Bear OS** to **VoltFlow**.
- Preserved **Blue Bear Electric** as the company/customer-facing brand.
- Updated admin, employee portal, customer portal, customizer, and exported-document language.
- Replaced the AI tab's generic **Print** button with **Export AI Draft / Save PDF**.
- AI export now validates that a draft exists, includes the selected project, adds a review disclaimer, and opens a clean print/PDF document.

## Deployment
Copy all files and folders into the GitHub repository root, commit, push, and allow Vercel to redeploy. No SQL migration is required for V8.
