# VoltFlow V8.2 — Service Territory Redesign

This release replaces the old three-card coverage section with a full-width technical 3D service territory map.

## Changes
- Removed the Proudly Serving city-pill panel.
- Removed the old Imperial Valley placeholder map.
- Removed the Local Expertise / Call Now card.
- Added the Southern California and Arizona 3D service territory graphic.
- Added animated grid movement, scan line, light sweep, corner HUD accents and desktop tilt interaction.
- Added responsive and reduced-motion behavior.

No database or Supabase SQL changes are required.
