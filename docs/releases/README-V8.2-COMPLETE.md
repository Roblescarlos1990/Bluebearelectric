# VoltFlow V8.2 Complete Refined Repository

This package is the complete GitHub-root release for the V8.2 service-territory redesign.

## Reviewed pages

- `index.html` — public homepage with working estimate form and full-width technical territory map.
- `services.html` — primary service overview and customer navigation hub.
- `industrial.html` — plant, controls, switchgear, testing, and maintenance positioning.
- `commercial.html` — commercial construction, upgrades, service, and maintenance.
- `residential.html` — homeowner service, upgrades, troubleshooting, and installations.
- `solar-bess.html` — solar and battery-storage support positioning.
- `service-repair.html` — troubleshooting, testing, repairs, and emergency response.
- `projects.html` — project portfolio and proof-of-work page.
- `about.html` — founder, qualifications, mission, and trust information.
- `contact.html` — Supabase-connected estimate request workflow.
- `admin.html` — VoltFlow command center, AI tools, documents, CRM, projects, and field operations.
- `customer-portal.html` — private customer access.
- `employee-portal.html` — field reporting and technician workflows.
- `customize.html` — theme preview and CSS customization helper.
- `system-check.html` — deployment asset and connection check.

## V8.2 changes

- Removed the three older service-area cards from the homepage.
- Added the full-width technical Southern California and Arizona territory map.
- Added scan, HUD, glow, and subtle pointer-tilt effects.
- Retained responsive and reduced-motion support.
- Updated visible legacy version labels to current VoltFlow wording.
- Preserved Supabase, admin, portals, estimate forms, field operations, and document tools.

## Deployment

Replace the contents of the local Git repository with everything inside this package, then commit and push through GitHub Desktop. No new SQL is required.
