# VoltFlow V8.6.5 — Premium Service Experience

This release expands the four primary public service pages into dedicated, information-rich sales experiences while preserving the V8.6 admin, CRM, estimating, billing, portals, content manager and Supabase foundation.

## Redesigned pages
- `industrial.html` — plant electrical, testing, shutdowns, maintenance, typical MCC PM and industrial FAQ.
- `commercial.html` — tenant improvements, lighting, continuity planning, phased work and facility FAQ.
- `residential.html` — homeowner-friendly services, interactive home-system explorer, trust content and panel-upgrade example.
- `solar-bess.html` — solar/BESS capabilities, interactive energy-flow explorer, maintenance intervals and corrective-repair example.

## New shared files
- `service-experience.js`
- `assets/js/service-experience.js`
- V8.6.5 component styles appended to both root and asset CSS copies.

## Installation
Replace the current repository contents with this complete package, commit through GitHub Desktop, and push. No new SQL migration is required.

## Important review note
Technical scope, standards, testing and maintenance language must be reviewed against the actual services Blue Bear Electric intends to offer. The pages intentionally avoid fixed pricing and do not claim NETA or manufacturer certification.
