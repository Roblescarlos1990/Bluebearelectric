# VoltFlow V8.6 — Professional Estimating & Billing

## Added
- Estimate headers, status workflow, validity, scope, exclusions, warranty, terms
- Categorized line items with internal cost and live margin visibility
- Reusable estimate templates
- Markup, tax, discount, deposit calculations
- Branded estimate PDF/print export
- Invoice conversion, status, PO, due dates, payment tracking
- Branded invoice PDF/print export
- Financial KPI dashboard and pipelines
- Global financial activity logging foundation

## Install
1. Replace repository files with this complete package.
2. Commit and push through GitHub Desktop.
3. Run `docs/sql/V8-6-ESTIMATING-BILLING.sql` in Supabase SQL Editor.
4. Hard refresh `/admin.html`.
5. Open a project → Estimate → save an estimate → create invoice → record a test payment.

Existing CRM, content manager, portals, projects, and public website remain intact.
