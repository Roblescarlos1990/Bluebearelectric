# VoltFlow V8.7.2 — Live Media & Customer Experience

## Included
- Multiple-file project uploads
- Upload progress and validation
- Immediate gallery redraw without a full-page refresh
- Supabase Realtime gallery synchronization
- Customer-visible/internal media controls
- Permanent media deletion with Storage cleanup
- Media search and category filters
- Customer project progress, milestone timeline, and upcoming visits

## Install
1. Replace the repository contents with this package.
2. Run `docs/sql/V8-7-2-LIVE-MEDIA.sql` in Supabase.
3. Commit and push through GitHub Desktop.
4. Test an upload in Admin > Project Workspace > Photos.
